# Solar-System Simulator

## Usage
### Install & Start
```bash
> git clone https://github.com/hinokaito/solar-system-simulator.git
> cd solar-system-simulator
> cargo run --release
```

### Operation
- MOVE: `W/A/S/D`
- VIEW CONTROL: `Q/E`
- UP/DOWN: `Space/LCtrl`
